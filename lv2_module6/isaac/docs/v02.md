# v02 팔 skill 학습 계획

v01(`policies/*.pt`)은 시뮬에 중력 앞먹임이 없었다. v02는 실기 `rl_arm_correction`과 같은 구조(**기준 동작 + 중력 앞먹임 + 처짐 적분 + 정책 잔차**)로 다시 학습하고 `policies/v02/`에 저장한다.

## 바뀐 점

- `place_env.py` `_gravity_ff`: `rl_arm_correction.hpp`의 `gravity::torques`를 torch로 옮겨 joint2·3 오프셋 `-τ/k`를 명령에 더한다 (`ff_gain=1`, `ff_max=0.2`; `--cfg ff_gain=0`이면 끔). 슬롯·집기·도달·세우기 env가 모두 이 경로를 쓴다.
- 처짐 적분(`corr`)은 앞먹임이 못 지운 나머지를 지운다. 오차는 `q_ref + 잔차 − q`.
- 실기와 한 가지 다르다: 실기는 앞먹임을 적분 오차에도 넣는다(비틀림이 엔코더 뒤에 숨음). 시뮬은 관절 각도 자체가 처지므로 오차에서 뺀다.
- 확인 (reach `target=above`, 적분 끔): 처짐 10.1 mm → 앞먹임 켜면 0.7 mm. 부호 반대면 20.4 mm.
- `train.py --out v02/x.pt`가 하위 폴더에 `.pt`·`.onnx`를 만든다. `train_queue.sh`는 `SUB=v02` · `XARGS=--sag_dr`를 받는다.

## 대상 skill (7개)

기준선이 100 %인 `move_pose`·`camera_clear_view`·`camera_look_down`과 주행 skill은 뺐다.

## 설정

env 512개 · 800 iter(v01은 1500, 처음부터 다시 학습) · `--sag_dr`(적분 이득 ×0.5~1.5, 처짐 ×0.7~1.5) · 평가 512판. 한 skill당 약 25분, 전체 약 3시간.

```bash
cd isaac
PYTHONPATH=$PWD/rl SUB=v02 ITERS=800 ENVS=512 EVAL=512 XARGS=--sag_dr \
  scripts/train_queue.sh place_cell pregrasp load_slot unload_slot pick_standing_puck stand_lying_puck regrasp_after_stand
```

결과 표: `logs/queue_summary_v02.tsv` (기준선 · 학습 뒤 성공률). 진행 로그: `logs/queue_<skill>.log`.
